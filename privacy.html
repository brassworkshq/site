Privacy policy

Last updated 21 August 2026

This policy covers this website and the private publishing tool that BRASSWORKS uses to upload its own videos to its own social accounts.

This website

This site is static. It sets no cookies, runs no analytics, embeds no third-party scripts and collects nothing about visitors. There is no account to create and no form to submit.

The publishing tool

BRASSWORKS uses an internal command-line tool to upload finished videos to the accounts it owns. The tool is not offered to anyone else — it has exactly one user, the operator of BRASSWORKS, acting on their own accounts.

  • It runs locally on the operator's own computer. There is no server, no hosted backend and no database.
  • Authorisation tokens are stored in a file on that computer and nowhere else. They are never transmitted to any party other than the platform that issued them.
  • It reads no personal data of any kind from any third party. It uploads a video file and its caption, and nothing else leaves the machine.

Google API data

The tool requests a single Google scope, https://www.googleapis.com/auth/youtube.upload, for the sole purpose of uploading BRASSWORKS videos to the BRASSWORKS YouTube channel. It does not read viewer data, comments, subscriber lists or analytics.

BRASSWORKS' use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Data obtained through those APIs is not transferred to any third party, is not used for advertising, is not sold, and is not read by any human other than the operator.

Access can be revoked at any time from myaccount.google.com/permissions, which immediately and permanently ends the tool's ability to upload.

TikTok API

The tool requests four TikTok scopes, and only these:

  • video.upload — place a finished BRASSWORKS video into the BRASSWORKS account's own drafts.
  • video.publish — post a finished BRASSWORKS video to the BRASSWORKS account directly, where that permission has been granted.
  • video.list — read the public view, like, comment and share counts of BRASSWORKS' own posts, so the operator can see which of their own videos performed.
  • user.info.basic — required by TikTok alongside video.list.

All four act on the operator's own account and no other. The tool reads no other user's data, reads no comments, follower lists or messages, and has no ability to act on any account it has not been explicitly authorised for. Tokens stay on the operator's machine. Nothing obtained from TikTok is sold, shared, transferred to any third party, used for advertising, or read by any human other than the operator.

Access can be revoked at any time from the account's TikTok settings, which immediately ends the tool's access.

Retention

Tokens are held only while they remain valid and are deleted when access is revoked or the tool is uninstalled. The view counts of BRASSWORKS' own posts are stored in a file on the operator's computer so that performance can be compared over time; that file contains no data about any other person, and nothing in it leaves the machine. No other data is retained, because none is collected.
